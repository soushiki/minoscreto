Minoscreto en Claude Code

Guía para instalar y usar el conector que anonimiza tus documentos antes de que Claude los lea.

Minoscreto cambia los nombres, cédulas, NIT, direcciones, teléfonos, correos, cuentas, radicados y placas de un documento por etiquetas como [PERSONA_1]. Todo ocurre en tu computador: Claude solo recibe el texto con etiquetas. Al final, Minoscreto vuelve a poner los datos reales en el resultado y lo guarda en tu computador.

Necesitas: Claude Desktop con la pestaña Code y el archivo minoscreto.mcpb que vino con esta guía.

1. Instalar (una sola vez · unos 10 minutos)

  1. Guarda el archivo minoscreto.mcpb en tu carpeta Documentos.
  2. Abre Claude Desktop y entra a la pestaña Code.
  3. Inicia una sesión nueva.
  4. Abre el archivo instalar-minoscreto.txt que vino con esta guía, presiona Ctrl+A y luego Ctrl+C. Es el mismo mensaje del recuadro de abajo.
  5. Pega el mensaje en la sesión con Ctrl+V y envíalo.
Configura el conector Minoscreto en Claude Code. No abras ningún documento mío.
1. Busca el archivo minoscreto.mcpb en mis carpetas Documentos, Descargas y Escritorio. Abre solo ese archivo.
2. Revisa si Node.js 20.19 o más nuevo está instalado. Si no, instálalo con: winget install OpenJS.NodeJS.LTS
3. Crea la carpeta %USERPROFILE%\Minoscreto y descomprime ahí el archivo con: tar -xf "<ruta del .mcpb>" -C "%USERPROFILE%\Minoscreto"
4. Regístralo para todos mis proyectos, con la ruta completa de node.exe:
   claude mcp add minoscreto --scope user -- "<ruta de node.exe>" "%USERPROFILE%\Minoscreto\mcp\server.mjs"
   Si el comando claude no existe, agrega en %USERPROFILE%\.claude.json, dentro de "mcpServers" del nivel superior:
   "minoscreto": {"type": "stdio", "command": "<ruta de node.exe>", "args": ["<ruta completa de server.mjs>"]}
5. Ejecuta claude mcp get minoscreto y dime si dice Connected.
6. Agrega esta regla a %USERPROFILE%\.claude\CLAUDE.md (créalo si no existe), sin borrar lo que ya tenga:
   "Documentos con datos personales (expedientes, contratos, poderes, documentos de clientes): para anonimizarlos o trabajar con ellos usa solo la herramienta anonimizar de Minoscreto. Nunca abras el original con lectura de archivos, terminal, Python ni skills de PDF o Word. Si las herramientas de Minoscreto no están cargadas, detente y avísame: no anonimices con un script propio."
  1. Cada vez que Claude pida permiso para ejecutar un comando, haz clic en Permitir (Allow).
  2. Si Windows pregunta si quieres permitir que la aplicación haga cambios, haz clic en Sí. Esto pasa solo si hay que instalar Node.js.
  3. Espera a que Claude te diga que Minoscreto quedó Connected.
  4. Cierra esa sesión y abre una nueva. Las herramientas de Minoscreto se cargan al iniciar cada sesión.

2. Anonimizar un documento (1–3 minutos)

Peligro: no arrastres ni adjuntes el documento a la sesión, y no pegues su texto. Así los datos reales le llegan a Claude. Dale solo la ruta del archivo.
  1. En el Explorador de archivos, haz clic derecho sobre el documento (PDF, Word, .txt o .md) y elige Copiar como ruta de acceso.
  2. En una sesión nueva de la pestaña Code, escribe Anonimiza, pega la ruta y di qué necesitas. Ejemplo: 
    Anonimiza "C:\Users\Ana\Documents\Caso Pérez.pdf" y hazme un resumen del caso.
Advertencia: si Claude empieza a leer el archivo, a explorar la carpeta o a escribir un programa propio, en lugar de usar anonimizar de Minoscreto, detenlo con el botón de detener (■) o con la tecla Esc.
  1. Revisa que lo primero que haga Claude sea usar anonimizar de Minoscreto.
  2. Revisa el resumen de datos ocultos que muestra Claude (cuántas personas, cédulas, etc.).

Junto al documento original aparecen dos archivos nuevos:

documento-XXXX_protegido.mdEl texto con etiquetas. Este sí se puede compartir.
Caso Pérez_diccionario-XXXX.jsonLos datos reales. No lo compartas ni se lo pidas a Claude.

3. Corregir lo que se ocultó (1 minuto)

  1. Si algo no debía ocultarse, díselo con su etiqueta. Ejemplo: No ocultes [PERSONA_3], es el juez.
  2. Si algo quedó visible y debía ocultarse, díselo. Ejemplo: Oculta también "Finca La Esperanza".

Claude anonimiza de nuevo y crea archivos con un código nuevo.

4. Recibir el resultado con los datos reales (1 minuto)

  1. Pídele a Claude que restaure su respuesta. Ejemplo: Restaura tu respuesta en un Word.
  2. Abre el archivo Caso Pérez-restaurado.docx que aparece en la misma carpeta. Claude te dice la ruta; los datos reales no aparecen en el chat.
Nota: también puedes restaurar un archivo que te devolvió otra IA. Ejemplo: Restaura "C:\...\respuesta.docx" con el diccionario "C:\...\Caso Pérez_diccionario-XXXX.json".

5. Bueno saber

  • Para documentos sin datos personales, la pestaña Code funciona como siempre.
  • Un PDF con contraseña no se abre: quítale la contraseña o usa minoscreto.netlify.app.
  • Un PDF escaneado sin texto no se puede leer: hazle OCR primero.
  • El PDF restaurado es de texto simple, sin el diseño original. Para conservar el formato, pide Word.
  • Ningún archivo se sobrescribe: si el nombre ya existe, se crea uno con (2).
  • Si recibes una versión nueva de minoscreto.mcpb, repite la parte 1 con el archivo nuevo.
  • Si algo falla, anota en qué paso ibas y qué dijo Claude, y avísale a quien te envió esta guía.
